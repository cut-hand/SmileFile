# 拾序 · SmileFile

[打开在线工具](https://cut-hand.github.io/SmileFile/)

无需 Python 或服务器的本地文件整理工具。请使用 Windows 或 macOS 的 Chrome / Edge，选择文件夹并授权读写后使用。文件在本机处理，不上传到服务器。

- 递归扫描子文件夹，整理前预览每个文件的原位置和目标位置。
- 通用方案按需创建视频、音频、文本、图片及未知类型文件夹。
- 视频项目方案包含 01.image 至 07.Timeline；文件名含 readme（不区分大小写）优先归入 05.readme，DRT 等剪辑工程归入 07.Timeline。
- 同名自动改名，可筛选重名并对比部分格式的内容。
- 可选整理后删除空文件夹，支持当前页面内撤销。

关闭页面会丢失一键撤销记录；整理日志保存在所选文件夹。大文件校验需要额外内存和临时磁盘空间。完整使用说明见 [使用说明](使用说明.md)。

## 部署

纯静态网页：index.html + style.css，使用 GitHub Pages 从 main 分支根目录发布。提交网页文件更新后自动部署。
